# Section 04 Works: the cabinet of ten folders (API note)

Source: `src/components/sections/Works.tsx`, `src/components/sections/works.css`, `src/components/sections/works/*` (`WorkCard`, `YoursCard`, `NoteCard`, `FilterRail`, `KeysCard`, `data.ts`, `strings.ts`). `export default Works` (also named). Mounted by `App` between About and Process. A cream `Sheet` (`id="works"`, page "Works", n = 4) that owns the `<h2>` (StrokeWord WORKS). Nothing to wire up: no props, no context.

## What it renders

1. **Head** (one row from 1340px): StrokeWord `WORKS` (h2, tint fill, accent shadow, `--wk-word` = 8.4vw, 4rem to 10.5rem) with the ghost count `(NN)` tucked against its last letter like a superscript (it follows the filter and slides in again when the number changes; on a phone it peeks out above the last letter), the sub from `WORKS_SECTION.sub` beside it (the `[ and ]` in it is drawn as two keycaps that never break across lines; on touch screens, `(hover: none), (pointer: coarse)`, the sub is `WORKS_UI.subTouch` and does not mention keys) and the **index card** (`KeysCard`, paper-clipped, tilted, `role="note"`): `[` Previous, `]` Next, `Esc` Close as three keycaps side by side. The card is hidden on touch and below 900px (no keyboard to press). 900 to 1339px: word and sub stack on the left, the card sits beside them. The head is about 150px tall at 1440 (it was about 330px), so the first folder shows in the first screen.
2. **Drawer rail** (`FilterRail`): a brass **label holder** (a typed card slips into it when the filter changes and its two lines are typed in steps: filter name + the file numbers on show, e.g. `FILES 02–03 & 07–08` (the last group joins with an ampersand)), then the **divider tabs** All / Editorial / Branding / Web / Illustration / Print with the counts from `categoryCounts()` (through `WORKS_SECTION.filters()`), on a slotted metal **bar** that takes the active tab's colour. The active tab is taller and fused with the bar. **All** is a pale blank divider (`IDLE_ALL_TONE`) unless it is the selected one, so the one black tab is always the active tab. A real `role="tablist"` (roving tabindex, Arrow keys / Home / End, automatic activation) that controls the grid (`role="tabpanel"`). A second brass plate, the **counter** ("In this drawer / 03 / 10 folders", `aria-hidden`), sits at the right end of the rail wherever the holder has empty paper beside it: 640 to 1339px (opposite the holder, above the tabs) and 1700px and up (end of the bar). From 1340px the holder sits beside the tabs (tab padding is trimmed to 14px between 1340 and 1459px so the six tabs end inside the bar on a 1366px laptop); below 1340px the holder stacks above the tabs. **Below 1000px the tabs never scroll sideways**: 640 to 999px they are a block of 3 x 2 equal tabs, below 640px rows of tabs that fill the line by label width (2 per row at 390px), and every row stands on its own strip of the bar (a repeating background on the tab row, pitch 54 + 12 + 8px; the single bar is hidden there).
3. **Cabinet** (the grid): ten folder cards, all the same size, + the drawer note (short drawers, desktop) + the empty last folder "Next folder: yours?", laid out by a recipe per filter (see "Layout").
4. A visually hidden polite status line (`role="status"`): "Showing 4 of 10 folders: Branding."

## Filtering

* State `filter: 'all' | Category`. Sources: the tabs, the drawer note's tab, and the window event `pm:filter` (`FILTER_EVENT`; `detail` = a `Category` or `'all'`; sent by the sheet meta bar and the cover quick tabs through `requestFilter(category)`). Unknown details are ignored. After a filter arrives from an event or the note, two animation frames later the rail is scrolled to the top of the viewport (`scrollIntoView({ block: 'start' })`, smooth unless `isStill()`), so the page makes one smooth move even though `requestFilter()` also scrolls to `#works`.
* Counts (never typed): All 10 / Editorial 3 / Branding 4 / Web 2 / Illustration 7 / Print 2.
* Re-flow: every card keeps its key (`slug-kind`) and carries a `layoutId`, so framer-motion glides it to its new cell; cards that do not match leave with `AnimatePresence mode="popLayout"` (fade + shrink 0.22 s). New cells land with the same spring as on the first scroll. Under reduced or paused motion (`useMotion().still`) the presence mode is `sync`, cards mount with `initial={false}` and the grid simply changes.
* The card tab relabels to the active category: `{CATEGORY} {NN}` where NN stays the project's own number (`n`), as in the template.

## Layout (`data.ts`)

* **Every folder is the same size** (owner request): one folder = 3 of the 12 columns x 1 row (`s` cells), so a row holds four. There is no featured (6 x 2) folder any more: `f` stays in the `CellKind` type and in `WorkCard`'s `featured` branch (blurb, roles slate and the "Open folder" label), which is never rendered now, so the card shows what the small folders always showed (print, title, kind, years chip, "My role" slate, CONCEPT stamp). The drawer note is also 3 x 1; the empty folder "Next folder: yours?" is kept: 3 x 1, or stretched to 6 x 1 (`w`) where it closes a row.
* **>= 1100px**: a 12-column grid with one recipe per filter (`LAYOUTS`), none leaving a hole: All = 10 folders in rows of 4, 4 and 2, then the empty folder across the last 6 columns (3 rows); Editorial = 3 folders + the note, then the empty folder stretched and centred below (2 rows); Branding = 4 folders, then the empty folder stretched and centred (2 rows); Web and Print = 2 folders + the note + the empty folder (1 row); Illustration = 7 folders + the empty folder (2 rows). Row height comes from the column width (`--rowh`); sizes inside a card are in `cqw`. Every card has a small pose (`POSES`: resting offset, tilt of +/- 0.3 to 0.5 degrees, tilt of the print, where the tab sits).
* **>= 1700px**: the head, the rail and the grid are one object of `--wk-max` = clamp(1240px, 100svh x 1.4, 1580px), centred; the row height is capped (`--rowh` = min(natural, max(430px, (100svh - 150px - gap) / 2))) and every print takes what the words leave (`object-fit: cover`, a crop per folder by `data-slug`).
* **640 to 1099px**: 2 columns, registry order, every folder one column wide (`TABLET_WIDE` is empty); the empty folder takes the full width only when it would sit alone in a row; the drawer note is hidden.
* **< 640px**: one generous column, no resting tilt or offset (JS: `flat`).
* Short drawers: **the drawer note** (`NoteCard`) is a taped sticky note in the gap of Editorial, Web and Print: "Only 2 of 10 folders live in Web." (the number is circled in pencil), "The rest are in the other drawers.", and a tab "Show all 10" that brings every folder back and lands the rail. It is not a link or a folder, so it only lands and leaves (no `layoutId`).

## The card (`WorkCard`)

A `<Folder as={motion.a} href="#/work/slug">`: a real link (middle click works), `layoutId={folderLayoutId(slug, 'works')}`, `onClick` runs `openWork(slug, 'works')` (modifier clicks stay with the browser), `onMouseEnter` / `onFocus` run `prefetchWorld(slug)`, `data-cursor="Open"`, accessible name `Title. Kind, years. Open folder.` (years only when they have digits). Back to front:

* the **file under it**: the paper edge of the next folder in the drawer shows on the side opposite to the tilt (`.pm-folder__body::before`); on hover the folder lifts out of the stack and that layer stays put;
* the **peek** (`peek.webp`, `alt=""`; Spelled Guilty's is `peek-suspect.webp`, a die-cut suspect derived from `stickers/suspect-10A.webp`, because the registry's peek is the paperback cover that is also the print: `PEEK_SRC` in `data.ts`): a cut-out that sticks out from behind the folder (z-index -1 in the folder's own stacking context) and rises on hover or keyboard focus;
* the **print**: the 4:5 `thumb.webp` (720x900 attributes, lazy, async) on a paper mount, tilted, taped where `ART` says so (Proyecto Contract and 44 Lab); concept folders carry the **CONCEPT stamp** (no sub-line), so concept art never travels unlabelled. The stamp is pressed on the folder's own paper in a strip under the words (the concept body has 40px of extra bottom padding; on the desktop grid the print gives those pixels back, so it is a hair shorter than 4:5 and `object-fit: cover` trims it), never over the print, the years chip or the kind line;
* the **text**: the title in the project's own display face (Bitter, Sora, Chango, Archivo, Orbitron, Gloria Hallelujah, Cormorant, Anybody, Cherry Bomb One; Gotet is set in the shell's Fraunces, lowercase red with an ink keyline and a blue offset like its wordmark), the kind, the years chip (hidden when the registry has no digits, e.g. "Early work"); featured folders add the blurb, the roles slate and a tab-shaped "Open folder" label (decorative: the whole card is the link); Every folder (featured or small) carries a "My role" slate (`.pm-wk-role`: an ink tag in the folder colour plus the roles at 15px in full ink); small folders put it under the kind line, and `--txt` (150px) reserves its room. Gotet sets `--on2` to full ink so its small lines pass 4.5:1.
* the **tab**: `{CATEGORY} {NN}`.

Faces: `loadWorldFonts(slug)` runs when the card is within ~2200px of the viewport (`IntersectionObserver`, disconnected after the first hit), so the face is in before the card is seen. Until it is decoded (`html.js .pm-wk-card:not([data-face]) .pm-wk-title { opacity: 0 }`) the title is invisible, then it fades in: no flash of the fallback. The Foley card's title reserves two lines (its wide face wraps at every width, the fallback does not) so no card ever changes height when a face arrives.

**Hover / focus.** The pointer lifts the folder with a spring (framer-motion `whileHover`: 14px up, the tilt relaxes to a quarter; stiffness 340, damping 17). Keyboard focus (`:focus-visible`) lifts it in CSS (`translate: 0 -14px` with `--ease-spring`), so a folder that gets focus back after a mouse click or a tap does not stay raised. Both raise the peek 6cqw and step the shadow up (`--pm-float`). Still motion (OS reduced or "Pause motion"): no lift, the peek stays put, the shadow still steps up.

**Focus ring (independent of motion).** `:focus-visible` on a folder, the empty folder included, draws a real 4px ink outline 8px off the box on an 8px paper mat (`box-shadow` in the sheet colour); the silhouette ring of the Folder primitive is turned off there so the two do not stack. The divider tabs and the drawer note's tab use a plain 3px outline (the primitive's drop-shadow ring is thin on ink and saturated paper). The lift is an extra on top.

## Art and fallbacks

All ten folders now have official card art (`public/works/<slug>/thumb.webp` + `peek.webp`, die-cut peeks included) and `OFFICIAL_ART` in `data.ts` lists every slug. `FALLBACK` (pieces from `public/works/<slug>/art/`) and the `<img onError>` handler remain only as a safety net: a listed file that fails once is remembered and the card switches to its fallback without repeated requests. `FALLBACK` can be deleted. `PEEK_SRC` overrides the registry peek for one folder (Spelled Guilty). Measured peek sizes are the files' real sizes.

## The empty folder (`YoursCard`)

A blank manila folder drawn with `Folder dashed` (hand-wobbled pencil outline through the `#pm-wk-pencil` SVG filter defined inside the section), a pencil-written tab "Next folder:", a dashed ghost peek with a question mark, an empty graphic frame (a box with a cross through it, as InDesign draws an empty picture frame) with "yours? Tell me what you're making." written over it in the thin hand face, and one real control, the Contact tab. It is `<a href="#contact">`; a plain click runs `scrollToSection('contact')`. 3 x 1 columns on the desktop grid, 6 x 1 (frame left, words and tab right) on short drawers; the same row layout applies from 1100 to 1199px with smaller lettering.

## Strings

`works/strings.ts` (`WORKS_UI`) adds the UI chrome that `src/lib/copy.ts` does not have: the keys card, the label holder, the drawer note, the status sentence, the accessible names. Merge candidates for `copy.ts`. Everything else comes from `@/lib/copy` (`WORKS_SECTION`, `CATALOG.button`, `CONCEPT.stamp`, `pad2`) and `@/lib/works`. No arrow glyphs are typed anywhere (SVG icons).

## Motion contract

* Folders land on the desk when they come within 90px of the fold (`LAND_MARGIN`: the peek and the tab are seen arriving and a 768px-tall laptop never shows a blank band under the rail; spring with one small overshoot, a tilt that settles, 0 to 0.28 s stagger by column), once. Pressing a folder (`whileTap`) pushes it back down 3px and shrinks it 1.2 %, so the click answers at once, before the shell opens the folder. The tab text, the holder card, the ghost count and the titles each have one short enter. Only `transform`, `opacity` and `clip-path` animate.
* Still: `initial={false}`, no `whileHover`, `AnimatePresence mode="sync"`, no CSS lift, peeks do not move, base.css shortens every CSS animation. Hidden initial states exist only under `html.js`.
* No loops, no rAF, no timers except the two animation frames of the filter landing (cancelled on unmount); every observer is disconnected.

## Shared requests and things other agents must know

* **Router (platform): Close loses scroll and focus when the URL carries a section anchor.** `openWork` pushes one entry and `closeWork` calls `history.back()`. When the entry before it is `…/#works` (the nav pills, a shared link) Chrome answers the traversal with its own scroll-to-fragment after the router's `scrollTo`, so the page jumps to the top of the section and focus ends on `<body>`. This section works around it locally (`dropSectionAnchor()` in `WorkCard.tsx`: it strips the anchor from the current entry before opening). The Cover deck and the Catalog bands have the same problem. One fix for every origin, inside `openWork` before `pushState`: `if (window.location.hash && !WORK_HASH.test(window.location.hash)) window.history.replaceState(window.history.state, '', baseUrl())` (keep reading `prevHash` first).
* `WORKS_UI` strings into `src/lib/copy.ts` (optional).
* The sheet meta bar and the cover quick tabs already dispatch `pm:filter`; nothing else is needed from them.

## Known weaknesses

* Below 1700px the cabinet fills the sheet; above it, the sheet has about 40px of cream each side of the cabinet at 1920.
* Nothing moves for about 0.4 s after Enter or a click (screencast of the preview build: the page stays as it is, then the desk dims and the folder body flies out in about 0.2 s), and the card's contents disappear when the flight starts. That is the shell's choreography (chunk and face loading, then the flight), not the card; it is only visible when opening from a card.
