# Architecture & contracts (read with ART_DIRECTION.md)

Stack: React 18 · Vite 5 · TypeScript (strict, `noUnusedLocals`) · Tailwind 3 (layout utilities only) · framer-motion · plain CSS files for bespoke components. Deploy: GitHub Pages from `main` (workflow builds `dist`). Base path `/`. Hash routing only.

Prefix all bespoke CSS classes: shell `pm-` (e.g. `.pm-folder`), worlds `w-<slug>-` (e.g. `.w-contract-table`). Never style bare elements outside `base.css`. No inline `<style>` tags. World CSS lives in its own file imported by the world component.

## Registry (`src/lib/works.ts`)
```ts
export type Category = 'editorial' | 'branding' | 'web' | 'illustration' | 'print'
export interface WorkMeta {
  slug: string; n: number                 // n = 1..10 (Pau's order)
  title: string; kind: string             // 'Magazine layout'
  years: string; group: 'Published work' | 'First steps' | 'Concept'
  categories: Category[]                  // first = primary (card tab)
  roles: string[]; tools: string[]; blurb: string
  color: string; ink: string; accent?: string   // folder color + text color on it (see ART_DIRECTION §2)
  thumb: string; peek?: string            // public paths for folder-card art
  links?: { label: string; href: string }[]
  concept?: boolean                       // show CONCEPT stamp + concept line
}
export const WORKS: WorkMeta[]            // 10 entries, sorted by n
```
Helpers: `workBySlug`, `byCategory(cat|'all')`, `nextOf(slug)`, `prevOf(slug)`.

## Router (`src/lib/router.ts`)
`useRoute()` → `{ kind: 'home' } | { kind: 'work', slug }`; `openWork(slug)` sets `location.hash = '#/work/'+slug`; `closeWork()` goes back to the previous section anchor and restores scroll; home anchors `#catalog` etc. Browser back/forward works. A world open locks body scroll (`html[data-world-open]`).

## World contract
```tsx
// worlds/registry.ts
export const WORLDS: Record<string, () => Promise<{ default: React.ComponentType }>> = {
  contract: () => import('./ContractWorld'), …
}
// inside a world
const { work, close, next, prev, reduced } = useWorld()   // from WorldShell
```
`WorldShell` renders the full-viewport overlay (background = `work.color`), the shared-element folder-open transition (framer-motion `layoutId={'folder-'+slug}` on the card body → overlay panel), the title tab (top-left, name + number), a Close tab (top-right, ESC), prev/next edge tabs (keys `[` and `]`, ignored while typing; never Alt+Arrow), focus trap + focus restore, `inert` on the page behind, scroll container (`.pm-world-scroll`) so worlds may scroll vertically or be fixed-height canvases. While the chunk loads it shows a film-leader loader. Worlds receive CSS vars on the shell: `--w-color`, `--w-ink`, `--w-accent`, `--w-bg`. Worlds must not render their own close button or title tab.
Every world ends with a `<WorldFacts>` slate (Role · Year · Tools · Links as **ticket stubs**) — provided by the foundation as `components/primitives/SlateLabel` + `Ticket`.

## Primitive APIs (foundation implements; others import)
- `<Folder tone? color ink tab="LABEL" count? tabX? flush? glass?>children</Folder>` — template tab technique (`--fr`), CSS vars `--c --on --on2`.
- `<StrokeWord text="PORTFOLIO" font="display" size ghost? draw />` — renders precomputed glyph paths from `src/lib/strokeWords.json` (generated by `tools/glyphs.mjs`; run `npm run glyphs` to regenerate), `pathLength=1` draw animation, hover wave.
- `<Sheet tone="cream|ink|marigold|ultraviolet|tomato" page="Catalog" n={2}>` + `<SheetMeta />`.
- `<Stamp rotate text color />`, `<Tape />`, `<Ticket href label cursor="Visit" />`, `<Sticker src halo />`, `<Scribble kind="underline|circle|arrow|burst" />`, `<Reveal as delay>`, `<SlateLabel items />`, `<ColorBars />`.
- Hooks: `useReducedMotion`, `useMotion()` (= `{ reduced, paused, still }`; `still` is true when the OS asks for reduced motion OR the visitor pressed "Pause motion"), `usePointerFine`, `useInView`, `useClock(tz)`, `useCopy`, `useBodyLock`.
- Motion switches live on `<html>`: class `js` (set by an inline script in index.html; hidden/initial animation states are written only under `html.js`) and `data-motion="paused"` (set by the Pause-motion control, persisted in localStorage inside try/catch). Ambient loops carry the class `pm-ambient` so one CSS rule stops them (`@media (prefers-reduced-motion: reduce)` and `html[data-motion="paused"]`); canvas/video loops must also check `useMotion().still` and pause off-screen and on `visibilitychange`.
- Focus ring (base.css): `outline: 2px solid var(--focus-in); outline-offset: 0; box-shadow: 0 0 0 4px var(--focus-out)`.
All primitives honor reduced motion and are keyboard accessible.

## Assets
Reference with `asset('/works/contract/cover.webp')` from `src/lib/asset.ts` (prepends `import.meta.env.BASE_URL`). Images need explicit `width`/`height`; use `loading="lazy"` + `decoding="async"` below the fold; videos `preload="metadata"`, `muted playsInline`, posters. Manifests (`public/works/<slug>/manifest.json`) describe what exists — read them instead of guessing.

## Dev & QA commands (every agent)
- Dev server (own port! Vite keeps one optimizer cache per `--port`): `cd C:/Users/User/Documents/Portofolio && npx vite --port <52xx> --strictPort --host 127.0.0.1` (run in background, kill when done). If a dependency seems missing, another agent may be installing: wait 60 s and retry. Dependencies are installed centrally; to add one take the lock: `until mkdir .locks/npm 2>/dev/null; do sleep 5; done; npm install <pkg>@<exact> --save-exact; rmdir .locks/npm`.
- Types: `npx tsc -b` (must be clean). Build: `npx vite build`.
- Screenshots: `node tools/shot.mjs '<plan json>'` (see the header of the file) → look at them with the Read tool. Check 1440×900, 1920×1080, 768×1024 and 390×844, plus `reducedMotion:true`.
- Verify there are no console errors / failed requests (the script prints them).
- Do not run git. Do not edit files you don't own. If you need a shared change (token, primitive, registry), write the request at the end of your report instead.
